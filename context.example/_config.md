# config.json — что здесь что

Файла нет — сервер всё равно поднимется на дефолтах. Он нужен, чтобы сервер
говорил о тебе, а не о «владельце этого сервера».

## person

| Ключ | Зачем |
|---|---|
| `name` | полное имя. Едет в `instructions`, в discovery и в промпт `ask` |
| `short` | как звать в тексте ответов («queued for Firstname»). Не задан — первое слово `name` |
| `headline` | одна строка о тебе. Идёт в `description` карточки сервера (там лимит 100 символов) |
| `site` | твой сайт. Из его домена собирается reverse-DNS имя в карточке |
| `pronouns` | нужны ровно в двух фразах ответа `leave_message`. Дефолт — they/them/their |

## server

| Ключ | Зачем |
|---|---|
| `id` | имя сервера в handshake (`serverInfo.name`) |
| `connectAs` | имя в примере `claude mcp add`. Не задан — берётся `id` |
| `url` | публичный адрес `/mcp`. Он же в карточке, в `llms.txt` и в шапке уведомления |
| `instructions` | текст, который агент читает перед первым вызовом. Пусто — соберётся сам из `person` и реального состава тулз. Свой текст всегда лучше |

## context.groups

Карта «тулза → файлы» и заодно порядок тулз в `tools/list`. Файл, которого нет,
тулзу не создаёт. Файл, которого нет в карте, получает свою — `get_<имя файла>`.
Хочешь другую склейку — пропиши `tool:` в шапке самого файла, она сильнее.

## tools

Переопределение того, что агент читает про `ask` и `leave_message`:

```json
"tools": {
  "ask": {
    "description": "текст, который агент видит в tools/list",
    "params": { "question": "описание параметра" }
  }
}
```

Файловые тулзы описываются не здесь, а полем `for_agent` в шапке своего файла —
описание живёт рядом с содержимым и не расходится с ним.

## ask

`enabled: false` по умолчанию: это единственная тулза, которая стоит денег.
Включил — положи `ANTHROPIC_API_KEY` в `.env` (BYOK, платишь ты). `callsPerDay`
и `tokensPerDay` — суточные потолки на ВСЕХ клиентов сразу, состояние в
`data/budget.json` переживает рестарт. Per-IP лимита мало: IP у агентов бесплатные.

## limits

Ведёрки по IP: общий поток в минуту, `ask` и `leave_message` — в сутки.

## discovery

`true` — сервер сам отдаёт `/.well-known/mcp/server-card.json` и `/llms.txt`.
Выключи, если эти файлы на твоём домене раздаёт сайт: две правды хуже одной.
