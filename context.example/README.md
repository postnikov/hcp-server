# context.example — твой личный слой

Это шаблон. Скопируй каталог и заполни своими словами:

```bash
cp -r context.example context
```

`context/` в `.gitignore` — твои файлы не уедут в чужой репозиторий, даже если ты
форкнул этот и коммитишь поверх. `context.example/` остаётся как есть.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `config.json` | кто ты, как называется сервер, какие лимиты. Единственное место с личными настройками |
| `who.md` | **обязательный минимум**. Один этот файл уже даёт рабочий сервер |
| `now.md` | чем ты занят сейчас; едет вместе с `who.md` в тулзу `get_profile` |
| `speaking.md` | ты как спикер |
| `services.md` | как с тобой работать |
| `channels.md` | где тебя найти |
| `writing.md` | что ты написал |
| `deploy.env` | адрес VPS и домен — нужен только если разворачиваешь через `deploy.sh` |

**Лишние файлы удаляй, свои — добавляй.** Сервер объявляет только те тулзы, под
которые есть файлы: нет `speaking.md` — нет и `get_speaking`. Положишь
`context/reading.md` — появится `get_reading`. Ничего перечислять в коде не надо.

## Как заполнить

Три пути, от быстрого к тщательному:

1. **Промптом.** Возьми `prompts/generate-my-hcp.md` из
   [`hcp-protocol`](https://github.com/postnikov/hcp-protocol), дай хорошей модели
   свои материалы — CV, посты, README проектов, транскрипты выступлений — и получи
   черновики этих файлов. Промпт задаёт вопросы только там, где материалов не хватило.
2. **Руками по шаблонам.** Открой каждый файл и замени плейсхолдеры. Заголовок `#`
   в первой строке — то, что агент увидит как название секции.
3. **Начни с одного `who.md`** и добавляй остальное, когда понадобится. Это не
   деградация, а нормальный режим: `18 файлов или ничего` — не про этот стандарт.

## Правила, которые стоит соблюсти

- **Только публичные факты.** Всё, что здесь лежит, отдаётся любому агенту без
  авторизации. Ничего про семью, здоровье, финансы и суммы сделок.
- **Цен нет вообще.** Вместо суммы — «pricing on request, use `leave_message`».
  Иначе твой прайс окажется в чужом кэше и будет жить там дольше, чем ты его держишь.
- **Английский.** К тебе придут агенты, а не читатели; английский — их общий язык.
- **`for_agent` в шапке — это описание тулзы**, которое агент читает ДО вызова.
  Пиши там, что внутри и когда это стоит дёргать, а не рекламу.
- Файл читается при старте процесса. Поправил — перезапусти сервер.
